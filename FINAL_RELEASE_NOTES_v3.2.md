# PropertyTour360 Designer Studio v3.2.0

## Scope

Graphics-quality renovation of the existing Designer Studio. All product workflows, backend contracts, canonical-model semantics, review controls and commercial/safety boundaries remain unchanged.

## Added

- Persistent high-quality Three.js scene with SSAO and high-quality SMAA profile.
- Bundled local HDR environment.
- Fifteen local GLB furniture/fixture assets with automatic object-name resolution.
- Nine complete PBR texture sets containing base colour, normal, roughness and AO maps.
- Correct per-room floor-material rendering from `room.floorId`.
- Fitted high-resolution sun shadows and selective room lighting.
- Window exterior, glass, sill and curtain dressing.
- Improved wall partition offsetting and architectural contact depth.
- Detailed procedural fallbacks when any GLB cannot be loaded.

## Unchanged

- Unified backend v3.1 contract.
- Capture evidence and geometry proposal workflow.
- Canonical model schema 2.1 and capture package schema 2.1.
- 2D editing, inspectors, catalogue APIs, versions, comments, approvals, exports and public links.
- Trust labels and professional-verification requirements.
