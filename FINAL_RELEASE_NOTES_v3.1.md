# Final release notes — Designer Studio v3.1.0

This release replaces Designer Studio v1.0 and the earlier v2.0 development package.

It is aligned to the unified backend v3.1.0 and corrected Android Mode B v3.1.0 contract. The website demonstration supplied the visual direction, while the semantic room model, versioning and backend-connected workflow remain authoritative.

The release does not include catalogue GLB files or proprietary textures. It supports them through backend records and external URLs, with procedural high-quality fallbacks so the Studio remains usable before catalogue ingestion.
